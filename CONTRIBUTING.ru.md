## Запустить проверки

Нужен Python 3.11+, дополнительные библиотеки не требуются:

```sh
python3 voicepack.py check --lang ru
python3 -m unittest discover -s tests -v
```

Проверяются архив, хеши, метаданные, каталог и ссылки, а также отказы установщика, блокировка повторной записи, откат, переводы и локальный HTTP-сервер. Тесты не обращаются к роботу. CI работает на macOS, Windows и Linux.

## Где что находится

| Путь | Содержимое |
|---|---|
| `installer/` | Облачный клиент, установка и откат |
| `installer/messages.en.json` | Английский интерфейс |
| `installer/messages.ru.json` | Русский интерфейс |
| `voicepack/` | Аудиоархив, манифест и русские расшифровки |
| `.my_local_dev/` | Локальные бэкапы и отметки незавершённых операций; исключено из Git |

Обновляйте обе версии документации вместе. Ключи сообщений и подставляемые поля должны совпадать в обоих языках. Данные аккаунта существуют только в памяти.

Пакет, манифест, каталог и образцы меняются вместе. Новую совместимость отмечайте только после испытания на устройстве. Автоматической публикации нет. См. [сторонний код](THIRD_PARTY.ru.md) и [источники аудио](docs/sources.ru.md).
