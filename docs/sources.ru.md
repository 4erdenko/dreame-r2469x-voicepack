# Источники

[← Главная](../README.ru.md) · [English](sources.md) · **Русский**

- Основа, служебные файлы и 8 сигналов: [официальный русский пакет Dreame](https://oss.iot.dreame.life/dreame-product/resources/4edabec3b754377f5890f69f3f98283d).
- Исходные реплики: `leather_bastadrs_loud.zip` из [Q0/ijai.vacuum](https://github.com/Q0/ijai.vacuum/tree/master/audio). 51 файл использован в 68 исходных и 7 составных событиях.
- Новые реплики: [AWS Polly](https://docs.aws.amazon.com/polly/latest/dg/available-voices.html), Maxim, русский язык, темп 110%.
- Дополнительная версия для сопоставления: [philliebe/leather-bastards-s10](https://github.com/philliebe/leather-bastards-s10).
- Облачный клиент: [RoboVoice](https://github.com/SashaEee/Trouver_audio_install); [лицензия MIT](../THIRD_PARTY.ru.md).

Единая открытая лицензия на смешанный аудиопакет не установлена. Перед публичным распространением нужно уточнить права на заимствованные записи; доступность исходников на GitHub не заменяет разрешения автора.
